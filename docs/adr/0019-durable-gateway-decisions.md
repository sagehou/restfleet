# 授权决定追加存储，签名晚于事务提交

schema 12 在既有备份占用下追加 Gateway 授权决定，使用占用行锁串行化首次签发、续期和明确吊销，并将决定、脱敏审计与 outbox 同事务提交；中心服务只对提交后的匹配决定签名。每个占用只绑定一个 runtime_id，revision 单调增加，幂等键只能重放仍为最新的相同决定；吊销终止该绑定，恢复不能通过普通续期绕过。继续使用 schema 11 的不可变占用期限，授权不晚于签发后 12h 或占用截止时间中的较早者，不通过释放再申请或改写原始期限实现续期。

## 后果

- 决定表仅追加；运行角色没有 UPDATE/DELETE，有任何历史记录时 Down 拒绝。新代码和 schema 12 必须在停止旧中心 writer 后一起部署，旧二进制不了解签名授权与释放限制，不能混跑。
- 续期重验身份、精确 ACK、配置、未释放占用与期限；明确吊销只依赖原始 ID/owner/运行绑定，即使 Agent/凭据被禁用或占用到期仍可执行，不把连接失败写成吊销。
- 未被明确吊销且尚未到期的任一历史授权阻止直接释放；即使记录了吊销，也必须另外证明请求、子进程和持久化清理完成。已知吊销同时阻止在线占用核验与材料借用/刷新，不自动释放 fence。
- 签名密钥只保存在中心服务配置中，默认禁用；不新增公共 API。本批不是生产 Gateway 协调器，密钥文件装载、可信投递、恢复、持久化回写和 AGT-005 仍需后续交付。
