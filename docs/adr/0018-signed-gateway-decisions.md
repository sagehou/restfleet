# 连接状态与签名授权决定分离

用户明确指出断网与吊销是两个状态：Gateway MUST 将控制连接状态与授权状态分离，只有可信中心的明确撤回决定才表示已知吊销，到期和失联均不能冒充吊销。沿用 ADR-0017 的有界授权，使用独立中心 Ed25519 密钥签名、固定 v1 域分离和严格有界编码，把决定绑定到占用、owner、运行实例和资源/凭据交付引用；Gateway 只持公钥并维护单调 revision，不接受重连或重放带来的自续期。已知吊销对同一绑定终止授权，后续恢复必须重新经过中心协调，而不是用更高版本普通续期复活旧绑定。

## 边界

这不修改 12h 签发上限、AGT-005 或到期仍保留 fence 的规则；远程最新状态可能未知，VALID 仅代表本地已验证决定仍在期限内。JSON 精确重编码拒绝歧义而非兼容未知字段，未来 wire 变更必须显式升级协议；具体编码和校验见部署规范 09 §7.11。

本批仅提供内部签名/验证及本地状态原语，不提供 HTTP 管理接口、数据库签发或生产 Gateway 接线。使用标准库而不新增 JWT/消息服务依赖；签名私钥绝不复用 Agent CA，密钥装载、事务签发、持久化恢复和连续占用将在后续 M4 交付。
