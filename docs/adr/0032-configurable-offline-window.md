# 离线窗口可配置，Gateway 不可达时暂停

用户于 2026-10-14 明确：离线窗口默认 72h、可配置；Gateway 离线应暂停备份并报错；减少重复测试，rclone 部署后验证。本决定取代 ADR-0016/0017/0018/0019 中固定的 24h 占用与 12h 授权上限，以及 AGT-005 的固定 12h 实验要求。

- 中心以 `RESTFLEET_GATEWAY_OFFLINE_WINDOW` 配置窗口，默认 `72h`，允许 `1m`..`720h` 的整秒时长。新普通授权零值使用配置，显式期限不得超过配置。窗口从最后中心签发起计算，实际截止仍受原占用限制；不承诺任意断线后额外完整 72h。代价是失联期间撤销最多延迟该窗口生效。
- schema 16 只扩展占用与授权请求的持久化上限至 30d，支持 72h 默认值及显式配置。旧占用不自动延长，续期不改原占用截止；到期不释放 fence，清理/封存/释放与失败 owner 不复活的约束保持。单次备份会话仍最多 24h。
- 中心控制 API/DB 不可用但 Gateway 持续在线时，在剩余授权内继续备份。Gateway 不可达、停止或重启丢失材料时 MUST 暂停并报错，保留 Agent 配对和配置；V1 不实现离线冷启动恢复。普通异常和授权到期不得要求重新 enrollment。
- 新测试只补配置、期限和权限隔离的关键边界，复用已有安全测试。rclone/provider 的真实认证、刷新、备份读回及兼容性在部署后的 GitHub Actions 验证，不阻塞前续源码交付；验证前不得声称相应后端生产可用。

升级 MUST 停止旧 Gateway 和中心 writer，迁移后统一使用新版；旧 reader 拒绝超过 12h 的签名授权。配置缩短不会撤回已签发的离线权限，需等待原到期或交付明确吊销。
